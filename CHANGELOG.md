## Uniray Changelog

# [2.0.0-alpha]

- Added external scene data encryption
- Added an installer-like external program
- Changed game simulation to run inside of Uniray
- Changed 3D model usage logic
- Re-introduced error handler 
- Added UI components for basic game object properties
- Various bugs and fixes

# [1.0.1-alpha]

- Improved file manager actions
- Changed overall application look
- Improved global optimization
- Various bugs and fixes

# [1.0.0-alpha]

- The engine is usable and can build projects
- Objects can be moved around
- Textures can be applied
- Projects can be loaded
